## Node System Overview
AOE uses a Node-Based Class Progression System. Each class is built from Core Nodes, with optional
Specialization Fractures and Augmentation Paths that allow players to deepen, customize, or
philosophically reshape their class. Designed to provide: clear class identity; optional
specialization without forced commitment.

## Core Nodes
- Each class has 20 Core Nodes, taken in a straight 1–20 progression
- Each Core Node costs 500 Ascension Points
- Core Nodes represent the primary abilities, traits, and mechanics of the class
- Core Nodes are the skeleton of the class; Fractures and Augmentations build off of them.

New Player Note: Core Nodes are the main abilities your class gains as it grows; you always follow the
Core Node path in order; even if you specialize or multiclass, Core Nodes are always the foundation.

## Multiclassing and Core Nodes
- Multiclassing is allowed in AOE
- When you multiclass, you always begin at Core Node 1 of the new class
- You must progress through that class's Core Nodes in order
- Core Nodes are never skipped or rearranged

## Specialization Fractures
Some Core Nodes have Specialization Fractures attached. A Fracture lets a player deepen and specialize a
specific Core Node, turning it into a defining part of their character.
- Fractures are optional; not every Core Node has one; fractures branch off a specific Core Node;
  a player is never required to take a fracture.

Free Fracture Node: the first node of any fracture path is always free; designed to be low-commitment
and exploratory.

Lesser Fractures: cost 250 Ascension Points; refinement, reinforcement, incremental improvement; enhance
how the Core Node functions without redefining it; all nodes directly attached to the first fracture
node are always Lesser Fractures. ("I care about this.")

Greater Fractures: cost 500 Ascension Points; deep commitment to the specialization; fundamentally alter
or strongly define how the Core Node behaves. ("This defines my character.")

Fracture Role: fracture paths allow exploration before commitment, preventing accidental or forced
identity lock-in.

Fracture Flexibility (AG Discretion): with Adventure Guide approval, a player may reselect fracture
choices, to support fun, experimentation and long-term enjoyment. The system is not meant to punish
players for exploring mechanics.

## Augmentation Nodes
Some Core Nodes are marked as Augmentation Nodes. Augmentations represent philosophical approaches to how
a class functions.
- Augmentation Nodes cost 0 Ascension Points
- Each class has one or more Augmentation Paths; augmentations are class-specific
- Once an Augmentation Path is chosen, you cannot mix paths

Choosing an Augmentation Path: when you augment a node, you select one Augmentation Path for your class;
once selected you are locked in and may only use augmentations from that path.
- You do not need to augment every eligible node; augmentations are optional per node
- Augmenting a node fundamentally changes how it works
- Augmentations do not add power sideways; they reshape behavior.

Augmentation Flexibility (AG Discretion): with Adventure Guide approval, a player may switch to a
different Augmentation Path (retraining, character growth, narrative change), so players are not locked
into something that is no longer fun.
