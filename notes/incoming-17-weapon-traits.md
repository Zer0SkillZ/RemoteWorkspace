# Incoming notes, part 17: Weapon unique traits + attack types
(Saved while waiting for ☆Go. Not yet applied to the app. Original wording kept.)

## Attack types (which stat an attack uses)
| Attack type | Stat |
|---|---|
| Graceful | Dexterity |
| Charm/PSI | Charisma |
| Might | Strength |
| Keen | Wittiness |
| Athose | Intelligence |
| Heft | Half Strength + Half Wittiness |
| Finesse | Half Dexterity + Half Wittiness |

Note: this expands the earlier rule "attack attribute is always Strength, Dexterity, Wittyness, or
Intelligence" (adds Charisma and two hybrids). Spelling here is "Wittiness"; earlier notes said "Wittyness".
